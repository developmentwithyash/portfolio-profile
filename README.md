## 🏛️ Featured Products & Systems

* **[YAAN](https://github.com/developmentwithyash/yaan):** Privacy-first, local-first sovereign mobile operating system (Kotlin Multiplatform + Supabase).
* **[ExamPrepOS](https://github.com/developmentwithyash/ExamPrepOS):** Offline-first exam preparation operating system with SM-2 spaced repetition and OLED distraction-free focus modes (Native Android, Jetpack Compose M3, Room SQLite).
* **[DRIFTBOUND: Open Roads](https://github.com/developmentwithyash/driftbound):** Stylized 3D open-world mobile street drifting game built in Unity 6 LTS with zero-allocation pure C# physics.
* **[Colab-Claude Reverse Proxy Bridge](https://github.com/developmentwithyash/colab-claude-bridge):** Authenticated streaming reverse-proxy gateway connecting local CLI workflows to remote cloud GPU clusters via Server-Sent Events (SSE).
* **[EOS & BOS Platform](https://github.com/developmentwithyash/eos-engineering-os):** Canonical state-machine-driven autonomous engineering and business operating system.

## ⚡ Tech Stack & Architecture

* **Runtime & Bundler:** ES6 Modules + Vite 8.3
* **3D & Canvas:** Three.js `v0.186.1`
* **Inertial Scrolling:** Lenis `v1.3.27`
* **Timeline Animations:** GSAP `v3.15.0` & ScrollTrigger
* **Styling:** Tactile Apple-caliber CSS with custom properties & OLED tokens
* **Hosting:** Vercel Global Edge CDN (sub-second LCP)
